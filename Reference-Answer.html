安徒生童话 13 篇 · 家长检查手册

您不需要读过原著也能使用：每篇先看「剧情梗概」掌握底细，再照着提问即可。

使用建议
  1. 别像考试。用聊天的方式问，比如"我最好奇这个故事的结尾了，你给我讲讲？"孩子复述出来了，就是读过的最好证明。
  2. 先问细节，再问含义。细节题答得出 = 读过；含义题答得出 = 理解了。孩子答不出细节但能讲出大致情节，也算读过。
  3. 理解题没有唯一答案。参考答案只是要点，孩子用自己的话讲出相近的意思就很好，别逐字对照。
  4. 答不上来别批评。可以说"我猜你可能没读到结尾，要不要明天读完了讲给我听？"把检查变成亲子阅读的约定。

1野天鹅

主题：爱、忍耐与坚持 —— 沉默中也能完成最伟大的拯救
梗概：公主艾丽莎的 11 个哥哥被恶毒的王后（继母）变成了野天鹅。艾丽莎必须在不能说话的前提下，用带刺的荨麻为每个哥哥织一件披风才能解除魔法。她忍受极度的疼痛、被误解为女巫差点被烧死，也始终不开口辩解，最终哥哥们全部获救。

✔ 检查是否读过（细节题）

  • 艾丽莎的哥哥们变成了什么动物？（野天鹅）
  • 她要用什么植物织披风？织披风时她被禁止做什么？（荨麻；说话——只要说一个字，哥哥们就会死）
  • 她一共要织几件披风？最后一件织完了吗？（11 件；最后一只袖子没织完，最小的哥哥还留着一只天鹅翅膀）

◇ 测试理解（开放题）

  • 艾丽莎明明被冤枉，为什么宁愿被烧死也不解释一句？
    • 说出来救的是自己的名声，但会害死哥哥；她选择了牺牲自己保全家人，坚持比辩解更重要。
  • 织荨麻疼不疼？她是怎么坚持下来的？换成你做得到吗？
    • 荨麻有刺，手会起泡溃烂；她靠对哥哥的爱和坚定的信念撑下来。引导孩子联系自己：坚持做一件难而正确的事。
孩子若说"她太傻了，解释一下不就行了"，其实是很好的讨论点：有时候沉默的坚持比争辩更有力量。

2老头子总是对的

主题：信任与包容 —— 一个家的和睦，比"占便宜"重要得多
梗概：老头子牵马进城，路上先换了牛，又换羊、鹅、鸡，最后换成一袋烂苹果。两个英国人打赌说回家后他妻子一定会骂他，老头子说不。结果老太婆对每一次交换都说"我的老头子总是对的"，英国人输了赌，把一袋金币给了他们。

✔ 检查是否读过（细节题）

  • 老头子最后换回来的是什么？（一袋烂苹果）
  • 两个英国人和老头子打了一个什么赌？（赌他回家后妻子会不会骂他，赌注是金币）
  • 老太婆听到"换成烂苹果"后是什么反应？（不但不生气，反而夸他做得对，因为正愁果园的苹果树去年一个苹果都没结）

◇ 测试理解（开放题）

  • 老太婆是真傻吗？英国人为什么输了？
    • 不是傻，而是信任。她看重的是"老头子总有自己的道理"，而不是每一步的得失；英国人用"吃亏就会挨骂"的思路打赌，所以必输。
  • 如果老太婆骂了他，结局会怎样？这个家还有什么不同？
    • 没有金币、没有拥抱和亲吻，家里会充满指责。引导孩子体会：互相体谅的家庭更温暖、更"富有"。
这个故事表面荒唐，其实是在讲夫妻之道。可以问问孩子："你希望我们家里人之间是什么样的？"很有共鸣。

3卖火柴的小女孩

主题：同情心 —— 看见穷人的苦难，学会心疼别人
梗概：除夕夜，一个卖火柴的小女孩光着脚在街头，一根火柴也没卖出去。她又冷又饿，不敢回家。她划亮火柴取暖，每根火柴里都出现一个幻象：温暖的火炉、喷香的烤鹅、美丽的圣诞树、慈爱的奶奶。最后她为了留住奶奶，划亮了整把火柴，冻死在墙角，嘴角带着微笑。

✔ 检查是否读过（细节题）

  • 小女孩每划一根火柴分别看到了什么？（火炉 → 烤鹅 → 圣诞树 → 奶奶）
  • 她为什么不敢回家？（没卖掉火柴会挨打，家里也一样冷）
  • 故事的结尾是什么？（她划亮一整把火柴留住奶奶，冻死在除夕夜的街头，脸上带着微笑）

◇ 测试理解（开放题）

  • 她冻死了，为什么安徒生要写她"嘴角带着微笑"？
    • 现实残酷，幻象美好；微笑写出她临终时的满足和对温暖的渴望，也加深了悲剧感——这份温暖只存在于幻想中。
  • 街上那么多人路过，为什么没有人帮她？如果你路过会怎么做？
    • 社会的冷漠是悲剧的一部分。引导孩子说出自己的行动：哪怕一杯热饮、一声问候，学会对弱者出手相助。
这是 13 篇里最沉重的一篇，适合睡前以外的时间讨论，重点落在"我们要做那个看见别人、帮一把的人"。

4拇指姑娘

主题：善良必有回响 —— 帮助别人，也是在为自己铺路
梗概：只有拇指大的姑娘从郁金香花苞里出生，被癞蛤蟆掳走，又被金龟子抛弃，历经漂泊。冬天她救了一只冻僵的燕子，在田鼠婆婆家住下，差点被迫嫁给鼹鼠。春天获救的燕子回来带她飞向温暖的花之国，她嫁给了花王子，得到了一双翅膀。

✔ 检查是否读过（细节题）

  • 拇指姑娘在冬天救了谁？她是怎么救的？（冻僵的燕子；用草编毯子、送水和粮食照顾它）
  • 她差点被迫嫁给谁？谁想让她嫁？（鼹鼠；田鼠婆婆）
  • 最后是谁带她离开了？她嫁给了谁？（燕子；花之国的花王子）

◇ 测试理解（开放题）

  • 拇指姑娘自己都过得那么苦，为什么还要救燕子？
    • 善良是她的天性，不图回报；而这只燕子后来恰恰成了救她的人——善良最终帮助了自己。
  • 金龟子嫌她丑、田鼠说嫁给鼹鼠才安稳，她为什么都不听？
    • 她心里向往阳光和自由，没有因为别人的眼光否定自己的感受。引导孩子：知道自己想要什么很重要。
可以追问："如果你是燕子，会回来报恩吗？"让孩子体会善意如何流转。

5坚定的锡兵

主题：坚定与尊严 —— 认定了的事，风吹浪打也不动摇
梗概：一个只有一条腿的锡兵，爱上了纸做的芭蕾舞姑娘。他被风吹落窗台、放进纸船漂进水沟、被鱼吞进肚子，历尽磨难却始终紧握钢枪、目视前方。回到房间后又被扔进火炉，火中他与心爱的姑娘一起熔化，第二天女仆在炉灰中发现一颗小小的锡心。

✔ 检查是否读过（细节题）

  • 锡兵有什么特别的地方？（少了一条腿——锡不够了）
  • 他经历了哪些磨难？（摔下窗台、乘纸船漂下水沟、被鱼吞掉、最后被扔进火炉）
  • 炉灰里最后留下了什么？（一颗小小的锡心）

◇ 测试理解（开放题）

  • 锡兵一路上从不说话，可为什么大家说他"坚定"？
    • 坚定不靠嘴说，靠行动：无论命运怎么折腾，他都站得笔直、握紧枪。这是内在的意志。
  • 你觉得他的结局是悲剧还是圆满？为什么？
    • 开放讨论：从身体看是悲剧，但他守护了爱情和尊严，留下"锡心"象征精神不朽。能自圆其说即可。
可以联系孩子的生活："有没有一件很难的事，你像锡兵一样咬牙坚持下来了？"

6皇帝的新装

主题：真话的勇气 —— 敢于说破的人，往往最小也最纯粹
梗概：两个骗子声称能织出"愚蠢和不称职的人看不见"的布。皇帝和大臣们谁也不敢承认自己看不见，皇帝"穿"着新装游行，全城百姓随声附和，只有一个小孩喊出"他什么也没穿呀！"谎言才被戳穿。

✔ 检查是否读过（细节题）

  • 骗子说这件新装有什么神奇的特点？（愚蠢的人、不称职的人都看不见它）
  • 是谁第一个说出皇帝没穿衣服？为什么别人都不说？（一个小孩；大人怕被当成愚蠢、不称职的人）
  • 被戳穿后，皇帝是怎么做的？（明知没穿，仍硬着头皮把游行进行完——因为他要保住皇帝的面子）

◇ 测试理解（开放题）

  • 皇帝、大臣、百姓都不傻，为什么全都上了当？
    • 不是眼睛的问题，是虚荣心和恐惧：怕承认自己"看不见"就等于承认愚蠢，于是互相欺骗、将错就错。
  • 为什么只有小孩敢说真话？如果你也在人群里，你敢喊出来吗？
    • 小孩没有利害顾虑，心里想什么就说什么。引导孩子讨论：说真话可能尴尬，但诚实比面子更宝贵。
这篇孩子普遍最熟，可以问得深一点："生活中有没有'皇帝的新装'式的事？"（比如大家都不敢指出的问题）

7蜗牛和玫瑰树

主题：奉献与索取 —— 两种活法，两种人生的分量
梗概：花园里，玫瑰树一年年开花，把芬芳献给世界。蜗牛却不屑一顾，认为世界与己无关，缩进壳里"给自己生活"，最后钻进土里，什么也没留下。玫瑰树则继续快乐地开花，把美给予世人。

✔ 检查是否读过（细节题）

  • 蜗牛和玫瑰树分别住在什么地方？（蜗牛住在玫瑰树下面/旁边的一个小花园里）
  • 玫瑰树是怎么回答"为什么要开花"的？（它说：我只能开花，不停开花——开花就是它存在的方式和快乐）
  • 蜗牛最后去了哪里？（缩进壳里、钻进泥土里，从此不再出现）

◇ 测试理解（开放题）

  • 蜗牛说"世界跟我没有关系"，你同意吗？玫瑰树给了世界什么？
    • 玫瑰树给世界花香和美丽，自己也在奉献中快乐；蜗牛只缩在自己壳里，什么也没留下。引导孩子比较两种人生。
  • 很多年后，人们会记得谁？为什么？
    • 记得玫瑰树——它付出过的美一直在延续。一个人的价值，常常在于他给了别人什么。
可联系生活："我们身边谁是'玫瑰树'？（医生、老师、环卫工……）"孩子答得出来就说明真懂了。

8海的女儿

主题：无私的爱与底线 —— 我可以为你牺牲，但我绝不伤害你
梗概：小人鱼救起落海的王子并爱上他。为变成人，她用美妙的声音和海巫婆交换双腿，且每走一步都如刀割。王子却娶了别人。姐姐们用头发换来一把刀：只要在日出前刺死王子，她就能变回人鱼。小人鱼把刀扔进大海，自己跃入水中化为泡沫，最终升入天空之女的行列。

✔ 检查是否读过（细节题）

  • 小人鱼用什么换来了人的双腿？代价还有什么？（她的声音；每走一步都像踩在刀尖上）
  • 姐姐们给了她什么办法自救？（一把刀——杀死王子，让他的血流到脚上，就能变回人鱼）
  • 她最后是怎么选择的？结局是什么？（把刀扔进海里，自己跳进大海化为泡沫，后来升入天空成为"天空的女儿"）

◇ 测试理解（开放题）

  • 杀死王子她就能活下去，为什么她宁可化为泡沫也不动手？
    • 她的爱是无私的：爱一个人就不忍伤害他。她用牺牲守住善良的底线——这是整个故事最闪光的地方。
  • 有人说她"太不值得了"，你怎么看？
    • 开放讨论：她失去了生命，却没有失去善良和尊严；安徒生让她升入天空，正是对这种精神的褒奖。孩子能有自己的理由即可。
引导落点：真正的善良，是哪怕自己吃亏、也不让别人受害。

9打火匣

主题：勇气与机遇（也藏着争议）—— 故事人物不一定都是"好人"
梗概：士兵在树洞里从女巫处得到打火匣和三只大狗。他取出洞里的金币、杀死了女巫，靠挥金如土结交朋友又陷入穷困。后来他用打火匣唤出三只狗，先救了牢狱中的自己，再让狗把公主背来相会，最后在刑场上救下自己，当上了国王、娶了公主。

✔ 检查是否读过（细节题）

  • 打火匣能唤出什么？一共有几只？（三只大狗：眼睛像茶杯、像磨盘、像圆塔）
  • 士兵靠打火匣做了哪三件大事？（要钱/取金币、从牢里救出自己、刑场上救他并救驾/把公主带来）
  • 故事的结局是什么？（士兵当上国王，娶了公主）

◇ 测试理解（开放题）

  • 士兵是"好人"吗？他杀了女巫、还让狗把公主偷偷背走，你怎么评价？
    • 关键讨论点：安徒生笔下的早期故事人物并不完美。可以让孩子分辨"勇敢/机智能干"与"道德正确"是两回事，学会不盲目模仿故事人物。
  • 如果没有打火匣，士兵能靠什么成功？
    • 引导思考：胆量（敢下树洞）、果断（抓住机会）是他自己的本领；但只靠运气和外物，风险很大。
这是少数"主角不完美"的篇目，最适合练批判性思维，别急着给孩子标准答案。

10丑小鸭

主题：接纳自己、不以外表评判人 —— 是金子总会发光，但成长要经历寒冬
梗概：一只又大又丑的小鸭子在鸭群和鸡群中被嘲笑、排挤，连兄弟姐妹也嫌弃它，它离家流浪，经历秋天孤独、冬天冻僵在冰面上（被农夫救起）。春天到来，它在湖里看见美丽的天鹅，低头照水才发现——自己就是一只天鹅。

✔ 检查是否读过（细节题）

  • 丑小鸭的"家"本来是什么样的？大家都怎么对待它？（它出壳就比别人大、长得丑，被鸭群啄、被鸡群嘲笑，连妈妈后来也希望它走远点）
  • 它冬天在冰面上差点怎么样？被谁救了？（冻僵在冰里；被一位农夫带回家）
  • 它是在什么时候、怎么发现自己变美的？（春天，它飞向天鹅群，低头看见水中自己的倒影——原来自己是一只天鹅）

◇ 测试理解（开放题）

  • 丑小鸭变美是因为运气，还是因为它自己坚持了下来？
    • 它本来就有天鹅的天性，但如果不熬过那些寒冬、不一直心怀对美的向往（它几次飞向天鹅），就等不到绽放的那天。
  • 鸭场里的动物们错在哪里？如果班里来了一个和大家不一样的同学，我们该怎么做？
    • 错在以貌取人、随众排挤"不一样"的人。引导孩子落到行动：不嘲笑差异，友善对待每个人。
可以反问一句："如果丑小鸭最后还是一只丑鸭子，它的流浪还有意义吗？"——把主题从"变美"引到"活出自己"。

11小意达的花儿

主题：想象力与童心 —— 相信花会跳舞的孩子，世界更辽阔
梗概：小意达发现花儿都蔫了。一个会剪纸的学生告诉她：花儿昨晚去王宫参加舞会，跳得太累了。夜里，小意达的娃娃们替她去看花儿的舞会，果然……后来花儿渐渐枯死，小意达和表哥、娃娃们一起为花儿们举行了隆重的葬礼，把她们埋进花园，相信夏天她们会再醒来。

✔ 检查是否读过（细节题）

  • 花儿们晚上去干什么了？谁告诉小意达的？（去王宫参加舞会；那个会剪纸、剪出跳舞人像的学生）
  • 谁替小意达去看了花儿的舞会？（她的两个玩具娃娃）
  • 花儿枯萎后，小意达做了什么？（和表哥、娃娃们为花儿举行葬礼，把它们埋在花园里）

◇ 测试理解（开放题）

  • 学生说的"花去跳舞"是真的吗？你愿意相信吗？为什么？
    • 故事留白：可以是想象力，也可以是童话里的真实。重点不是真假，而是拥有想象，世界才有趣。
  • 小意达为什么认真地为花儿办葬礼？这说明她是个怎样的孩子？
    • 她温柔、把花当作有生命的朋友；对万物有感情的人，内心柔软而丰富。
低年级孩子最爱这篇。可以顺势聊："你觉得花晚上会去哪儿玩？"听听孩子自己的想象。

12枞树

主题：珍惜当下 —— 总盼着"以后"，会错过"现在"
梗概：小枞树在森林里总是不满意：嫌自己太矮、嫌太阳和风，一心盼望快点长大。被砍倒做成圣诞树后，它度过了一生中最辉煌的一夜（蜡烛、金苹果、孩子们的欢呼），随后被扔进阁楼，给老鼠讲故事中度过岁月，最后被劈开当柴烧。它一生只说过"完了！"——只在新婚夜前夕说了"太幸福了"，可一切已经结束。

✔ 检查是否读过（细节题）

  • 枞树在森林里时最大的愿望是什么？（快点长大、长高，被砍去见大世面）
  • 它当圣诞树的那一夜经历了什么？（被装点蜡烛、彩旗、金苹果，孩子们又跳又喊，是它一生中最辉煌的一夜）
  • 它最后的结局是什么？（在阁楼上度过后半生，最后被劈成柴烧掉）

◇ 测试理解（开放题）

  • 枞树最快乐的到底是哪一段？它自己当时知道吗？
    • 是在森林里的阳光岁月，和做圣诞树的辉煌一夜。可惜它要么嫌弃前者、要么没意识到后者转瞬即逝——它总是在盼望"下一次"。
  • 枞树总说"完了！完了！"，如果它能重来一次，它应该怎样活？
    • 珍惜眼前的每一天：在森林里享受阳光，在圣诞夜好好感受快乐。引导孩子：幸福不是等来的，是当下体会出来的。
可以联系孩子："有没有总盼着放假，结果假期结束了才想起其实每一天都挺好的？"

13一个豆荚中的五粒豆

主题：平凡的奉献也能创造奇迹 —— 生命的价值在于给别人带来希望
梗概：豆荚里的五粒豌豆各自怀揣梦想飞向世界：有的想飞到广阔天地，有的想飞进太阳，有的只想睡大觉。其中一粒落进顶楼一个小病女孩窗台的裂缝里发了芽、开了花。女孩每天看着它长大，身体渐渐好起来。母亲说，这粒豌豆简直成了一个小花园。其他豌豆有的进了鸽子肚子、有的落进水沟，各自了结。

✔ 检查是否读过（细节题）

  • 五粒豌豆各自落到了哪里？（鸽子肚子、屋顶水沟、广大的世界（被鸽子吃掉）、太阳里（进了水沟）……其中一粒落进小女孩窗台的裂缝）
  • 窗台边住着一个怎样的女孩？（一个生病卧床很久、几乎站不起来的小女孩）
  • 那粒豌豆最后怎么样了？女孩呢？（它生根发芽、开出粉红色的豌豆花；女孩看着它一天天有精神，慢慢好了起来，能自己坐起来、站起来）

◇ 测试理解（开放题）

  • 五粒豌豆里，哪一粒活得最有价值？为什么？
    • 落进窗台的那粒——它没飞多远、没干什么大事，却让一个病中的女孩燃起希望、恢复了健康。价值不在"飞得远"，而在"给了别人什么"。
  • 安徒生说它"也该算是最了不起的"，你觉得"了不起"的标准是什么？
    • 开放讨论：能给别人带来幸福和希望的，哪怕再平凡，也是了不起的。
可以问孩子："如果你是那粒豌豆，你想落在哪儿？"从孩子的答案里能看到他的价值观。
